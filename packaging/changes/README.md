# Release Notes

One file per release, named after `WINNOW_VERSION_LABEL` in `CMakeLists.txt`
(e.g. `3_beta3.md`). It becomes the "Release Notes" section of that version's GitHub
release notes. Write plain Markdown, usually a bullet list, without a heading.

Menu `G` uses it when it creates the release. To change the notes afterwards, edit the
file and choose `N` in `deploy.command` or `deploy.ps1`. See `notes/Deploy.md` §3 and §7.1.
