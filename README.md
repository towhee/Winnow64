# Winnow
Image asset manager / editor

Winnow is a image viewer that runs on a Mac or PC.  Originally the primary objective of the program was to efficiently ingest (select and copy) images from a camera media card to your computer.

Winnow has grown a bit.

  •  Library with keywording (in development)
  
  •  Develop (in development)

  •  Mapping (in development)
  
  •  Focus stack module
  
  •  Framing
