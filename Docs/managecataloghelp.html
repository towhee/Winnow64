Manage Catalog

The folders in the Catalog Scope table make up your Library. They are scanned in the background, so their images can be found in the Library without opening each folder.

Only folders listed here are catalogued. You can still browse any other folder, but it is not added to the Library.

Catalog Scope

Each row is one rule: an Action (Include or Exclude), a Folder path, whether the rule reaches into Include Subfolders, and how many Images the folder holds on disk now.

Exclude a folder to carve a branch out of an included folder. An exclusion always wins, wherever it sits in the table.

Append adds a folder at the bottom of the table, and Remove deletes the selected rows.

Changing the table does nothing straight away, so you can make several changes in a row. A highlighted line under the table says that there are changes waiting.

When you have finished editing, press Scan to apply the changes. Closing the window applies them too.

Removing a row removes its images from the catalog when the changes are applied, and you are asked to confirm first. The image files themselves are not affected.

The table cannot be changed while a scan is running.

Catalog Information

Catalogued is what the catalog holds, and On disk is what the folders in the scope hold. When they differ, Status says how many images are still to be catalogued; press Scan to catalogue them.

See which opens the Catalog Diagnostics report, which lists the images behind the difference. It is also in Help > Diagnostics.

Scanning

Scan starts a background scan, and becomes Stop while one runs. Its progress shows here and on the status bar.

After you change the table, Scan scans only the folders you added, so a new folder does not wait for the rest of the catalog to be rechecked. With no changes waiting, Scan rechecks the whole catalog.

You can close this window during a scan: it continues in the background, and resumes at the next launch if Winnow quits first.

Duplicates

A duplicate is another image in the Library with the same capture time, file type and pixels. For a raw file the pixels are its embedded preview. For a video, the duration is compared instead of the pixels. A raw file and its JPEG are not duplicates, and neither are burst frames.

Duplicates checks the whole Library, and becomes Stop while it runs. Its progress shows here and on the status bar. It cannot run during a scan.

Only images that share a capture time, file type and size are opened, so most of the Library is never decoded. What a check finds is kept, so a stopped check picks up where it left off.

You only need to press it once. After that, images added to the Library are checked as they arrive, and moving an image to the trash updates its twin.

Duplicates found in Catalog Information says how many images are duplicates, in how many groups. To see them, use Filters > Status > Duplicates found.

A duplicate's thumbnail number is bright red, even when thumbnail numbers are turned off. Hover over it to see how many other images match, and where they are.

To tell which images are copies of which, click a duplicate. Its own number and its twins' numbers turn white, so they stand out from the other red numbers.

To see only a duplicate and its twins, select it and choose Show Duplicates of This Image from the thumbnail right-click menu or the Edit menu. It appears in Filters > Status > Duplicates of. Uncheck it there to go back to the filters you had before. Trashing a duplicate from it goes back to them too.

If the copies are meant to be there, select them and choose Edit > Duplicate Okay (also on the thumbnail right-click menu, which shows it only when a selected image is a duplicate). The check then ignores them and their numbers turn purple. Okaying one image of a pair clears both. Choose it again to undo.

Duplicates okayed in Catalog Information counts them. The Duplicate column in the table view shows Duplicate or Okayed for each image.

Collapsing sections

Click a section title to collapse or expand it. A collapsed section shows a one-line summary. Right-click a title for Expand all and Collapse all.
