Manage Catalog

The folders in the Catalog Scope table make up your Library. They are scanned in the background, so their images can be found in the Library without opening each folder.

Only folders listed here are catalogued. You can still browse any other folder, but it is not added to the Library.

Catalog Scope

Each row is one rule: an Action (Include or Exclude), a Folder path, whether the rule reaches into Include Subfolders, and how many Images the folder holds on disk now.

Exclude a folder to carve a branch out of an included folder. An exclusion always wins, wherever it sits in the table.

Append adds a folder at the bottom of the table, and Remove deletes the selected rows.

Changing the table does nothing straight away, so you can make several changes in a row. A highlighted line under the table says that there are changes waiting.

When you have finished editing, press Scan to apply the changes. Closing the window applies them too.

Removing a row removes its images from the catalog when the changes are applied, and you are asked to confirm first. The image files themselves are not affected.

The table cannot be changed while a scan is running.

Catalog Information

Catalogued is what the catalog holds, and On disk is what the folders in the scope hold. When they differ, Status says how many images are still to be catalogued; press Scan to catalogue them.

See which opens the Catalog Diagnostics report, which lists the images behind the difference. It is also in Help > Diagnostics.

Scanning

Scan starts a background scan, and becomes Stop while one runs. Its progress shows here and on the status bar.

After you change the table, Scan scans only the folders you added, so a new folder does not wait for the rest of the catalog to be rechecked. With no changes waiting, Scan rechecks the whole catalog.

You can close this window during a scan: it continues in the background, and resumes at the next launch if Winnow quits first.

Collapsing sections

Click a section title to collapse or expand it. A collapsed section shows a one-line summary. Right-click a title for Expand all and Collapse all.
