History

What it does

History lists every develop action on the current image, newest first, with the value it set — "Exposure  +0.35", "Sky: Contrast  -12", "Crop". The bottom entry is always Original: the image with no develop edits at all. An image that already had edits the first time Winnow saw it shows Saved settings just above Original.

A whole slider drag is one entry, not one per tick, so the list reads as the steps you actually took.

Going back

  • Hover an entry to preview that state on the image. Nothing changes until you click; moving off the list puts the current state back.
  • Click an entry to go back to it. The sliders, masks and crop all return to that state, and the entries above it are dimmed.
  • Click a dimmed entry to go forward again. But edit from an earlier entry and the dimmed entries are discarded — like undo, a new edit starts a new branch.

Before / After

Press \ (Develop menu > Before / After) to flip the image to Before — the Original entry — and press it again for After, where you are now. Unlike a hover it stays on Before until you press \ again, make an edit, move to another image, or open a mask or spot tool.

Multiple images

An edit made with several images selected lands on all of them, and each one gets its own History entry. The entries are linked: going back to that step on one image moves the other selected images back to the same step.

What is kept

History is per image and is kept between sessions. Each image keeps its last 100 steps; when older ones are dropped, a row above Original says how many. Original itself is never dropped.

If the image was edited somewhere Winnow did not see — on another computer, or from a restored sidecar — its history no longer leads to the picture on screen, so it is set aside and starts again from Original and Saved settings. The edits themselves are always kept: they live in the sidecar, and History is only the record of how you got there.

The panel

  • Press H to show the History panel in Develop. It shares the dock with Presets (P); drag the divider between them to share the space.
  • Click a band's arrow or title to fold that section away.
  • Right-click anywhere in the panel for Expand all, Collapse all and Solo mode (only one section open at a time).
  • Copy and Paste at the foot of the panel copy develop settings from this image and paste them onto another.

Related

  • Edits — its menu's Reset all edits wipes the recipe and the history together.
  • Presets — applying a preset is one History entry, so clicking the entry below it undoes the preset.
