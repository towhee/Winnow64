Renaming images

Rename works on the selected images, or on the picks if you choose them. It renames the files on disk. Sidecar files go with them, so ratings, keywords and Develop edits still apply after the rename.

Simple rename

Available when one image is selected. Type the new name without the extension; the extension is kept. For example, DSC_0042.ARW renamed to Sunset becomes Sunset.ARW.

By default every file that shares the base name is renamed together. The base name is the part before the extension. Renaming x.tif to y in a folder that holds

  x.arw   x.jpg   x.tif   x.xmp   x.tif.xmp

renames all five:

  y.arw   y.jpg   y.tif   y.xmp   y.tif.xmp

Winnow lists the extra files it renamed when it is done. A file name that is already taken is refused, so nothing is overwritten.

Only rename the selected file

Tick this to rename just the selected image and the sidecar files that belong to it. Everything else that shares its base name is left alone. In the same folder, renaming x.tif to y gives

  x.arw   x.jpg   y.tif   x.xmp   y.tif.xmp

Here x.xmp stays put because it belongs to x.arw, not to the TIFF. The next section explains how Winnow decides which sidecar belongs to which file.

The option is greyed out when Combine Raw+Jpg is on and the image is a combined raw+JPG pair. A combined pair is one thumbnail, so renaming one half would leave the hidden other half behind under the old name. Turn off Combine Raw+Jpg to rename one of the pair on its own.

Which sidecar belongs to which file

An XMP sidecar holds an image's rating, colour label, title, keywords and Develop edits. Winnow follows Lightroom's naming, which depends on the file type:

Image typeImageIts sidecar
Raw (ARW, NEF, CR3, ORF...) and HEIC x.arwx.xmp
JPEG, TIFF, PNG and DNG x.tifx.tif.xmp

Why there are two styles: Lightroom writes metadata inside JPEG, TIFF, PNG and DNG files, and ignores any .xmp beside them. Only raw and HEIC files get a sidecar, named x.xmp. So when a raw and a JPEG share a base name, x.xmp is the raw's. Winnow gives the JPEG its own x.jpg.xmp, so the two never mix: an edit to the JPEG cannot change the raw's Lightroom metadata, and the reverse is also true.

The same rules apply to .txt sidecars.

Older sidecars

Older versions of Winnow wrote x.xmp for every file type. A JPEG, TIFF, PNG or DNG still reads an old x.xmp as long as no raw file shares its base name. Once a raw is beside it, x.xmp is the raw's sidecar.

When you rename a JPEG, TIFF, PNG or DNG on its own and it is still reading an old x.xmp, Winnow first gives it its own sidecar. The old file is renamed to x.tif.xmp. If another image may also read it, it is copied instead, so that image keeps its settings too. The new sidecar is then renamed along with the image.

Template rename

Template rename builds each new name from a filename template. The template can include the original name, the capture date and time, camera details and a sequence number ({XXXX}). Use Edit templates to create or change templates. The Example line shows the result for the first selected image.

Template rename always renames the whole base-name group of each image, the same as simple rename does by default. If a new name is already taken by another file, that file is renamed out of the way first by adding -0 to its name.

Images from several folders

In Library and Catalog modes, and when subfolders are included, the selection can come from more than one folder. Each image is renamed in its own folder; nothing is moved between folders. The sequence number continues from one folder to the next instead of restarting. The suggested start number is one past the highest number already used in any of the folders. So one rename never gives two images the same number.

Locked files

On macOS, a file locked in the Finder (Get Info → Locked) cannot be renamed. Winnow checks for locked files before the dialog opens and lists them. Unlock them and try again.
