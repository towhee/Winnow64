What a keyword is

A keyword is a word you attach to a photograph so you can find it again — Heron, Vancouver Island, Client work. An image can carry as many as you like.

Keywords are filed in a tree, so Heron can sit under Bird, which sits under Fauna. A keyword is its whole path: Fauna > Bird > Heron. Two keywords with the same name in different branches are two different keywords, so a Vancouver in British Columbia and a Vancouver in Washington keep their own images. Because names repeat, only the last part is shown — hover any keyword to see its full path.

Winnow writes keywords into each image's XMP sidecar, which is where Lightroom and other applications read them from.

The two halves of the panel

At the top, under Selected images tags, are the keywords carried by the images you have selected. This is where you put a keyword onto a photograph, and where you take one off.

At the bottom, under Keyword list, is your own vocabulary: every keyword you have available to use, in its tree. Adding, renaming, moving or deleting here changes the list, not your photographs. If images would be affected, Winnow asks first and tells you how many.

Tagging the selected images

Select one or more images, then do any of these:

  • Type in the Add keyword box. As you type, matching keywords are offered with their branch shown faintly beside them, so two keywords sharing a name are two distinct choices. Press Return without choosing one to create the keyword exactly as you typed it.
  • Double-click a keyword in the list, or select it and press Return.
  • Drag a keyword from the list up onto the tags.
  • Drag images from the thumbnails onto a keyword in the list.

To remove a keyword, click the × on its tag. It is removed from every selected image, along with anything filed beneath it — taking Fauna > Bird off an image cannot leave Fauna > Bird > Heron on it.

A dot beside a keyword in the list marks one the current image already has.

What the tag markings mean

  • A plain tag is on every selected image.
  • * means only some of them have it. Click the tag to give it to all of them.
  • ? means the image carries a keyword that is not in your list — written by another application, perhaps, or left behind by a rename you chose not to apply. Click it to add it to your list, where its own path says it belongs.

Organising your list

Right-click any keyword for Rename, New keyword inside, Insert parent above and Delete. Drag a keyword onto another to move it there; a keyword cannot be dropped inside itself, and the cursor says so before you let go.

The Find keyword box above the list finds a keyword by name or by synonym, keeping its parents visible so you can see where it sits.

The number beside a keyword is how many images carry it. It counts everything filed beneath it as well, so Fauna's number already includes your herons, and there is nothing to add up. A blank means none. Only images Winnow has catalogued are counted, so a keyword used only in folders that have never been indexed shows no number. The Manage Catalog dialog (File > Manage Catalog...) is where you say which folders those are.

Deleting a keyword removes it from your list only. Images already tagged with it keep it in their own files, where it shows as a ? tag.

When images need updating

Renaming or moving a keyword changes your list at once. Photographs already tagged with it still carry the old keyword in their own files, so Winnow asks what to do and tells you how many images each choice would rewrite:

  • This folder — only the images in the folder you are looking at.
  • Everywhere — every catalogued image carrying it, including folders that are not open.
  • Not now — leave the files alone. Those images show the old keyword as a ? tag until you deal with it, so nothing is lost track of.

Starting from what you already have

Two commands on the right-click menu fill your list without any typing:

  • Build vocabulary from catalog — adds a keyword for everything Winnow has already indexed in your pictures.
  • Import Lightroom keywords... — reads a keyword list exported from Lightroom, hierarchy and synonyms included.

Both merge. Neither ever removes a keyword you created, and running either a second time adds only what is new. Export keywords... writes your list back out in the same format.

Tidying keywords that sit outside the tree

Keywords from an application that never wrote a hierarchy arrive as bare names — Nanaimo rather than Location > Canada > BC > Vancouver Island > Nanaimo. They work, but they pile up at the top of your list beside the branches they belong in.

Tidy flat keywords... on the right-click menu files them all in one go. It lists every such keyword with how many images carry it, and what it matched in your keyword list. For each one you can:

  • Move it into the branch shown — the deepest match is chosen for you, and you can pick another or type any keyword path.
  • Remove it from those images. This is the default for a name that matched nothing, which is usually a container name such as Location or Fauna: an image filed under Location > Canada is already found by searching for Location, so the bare name adds nothing.
  • Leave alone.

Rows marked review matched more than one branch — hover the match to see the alternatives with the number of images each already holds.

The Show list above the table is how you deal with a whole class of keywords at once. To file every keyword that matched exactly one branch, choose Matched one branch and press Move; then look at Matched several — review at your leisure. The three buttons act on the rows you have selected, or on every row shown if you have selected nothing — the note beside them always says which.

Apply carries out every row's Action, not just the rows you selected, and its button says how many keywords that is.

Applying rewrites the keywords in each image's own file or sidecar, everywhere in the catalog, whether or not the folder is open. Winnow tells you how many images that is and asks once more before it starts. It cannot be undone from inside Winnow.

Finding images by keyword

The Keywords category in the Filter panel is the same tree. Check a branch to find everything beneath it — checking Fauna finds your herons without opening the branch — or Opt+click (Alt+click on Windows) to leave a branch out, so you can include Location and exclude Location > USA.
