Bookmarks

The Bookmarks panel keeps a list of folders you frequently visit so you can return to them without navigating the folder tree each time.

Bookmarks follow the Source panel's Folders | Library switch. In Folders, selecting a bookmark also selects the folder in the Folders tree, which can be a quick way to navigate to a folder there. In the Library, a bookmark works like clicking that folder in the Library tree.

Add a bookmark

Right-click a folder in the Source panel's Folders tree and select "Add Bookmark", or drag a folder from there (or from Finder/Explorer) onto the Bookmarks panel. The folder is added to the list and stays there between sessions.

Open a bookmark

Click a bookmark to select that folder. The image list and thumbnail view update to show the eligible images in that folder.

When the Source is the Library, clicking a bookmark shows only the Library's images in that folder and the folders inside it, the same as clicking the folder in the Library tree. The folder is checked in the Filters panel's Folders category; clear that filter to see the whole Library again.

A bookmark the Library has no images in is shown in red and cannot be clicked. Switch to Folders in the Source panel to open it.

Remove a bookmark

Right-click a bookmark and choose Remove Bookmark. The folder itself is not affected — only the shortcut is removed from the panel.

Image counts

If image counts are enabled in Preferences, each bookmark shows the number of eligible images in that folder. In the Library it shows the number of Library images in that folder and the folders inside it, the same number the Library tree shows. Use the refresh button in the title bar to recompute the counts.

Drag and drop

You can drop thumbnails onto a bookmark to move or copy them into that folder. Hold the modifier keys to choose the operation:

  • No modifier — move
  • Opt/Alt — copy

Each image's sidecars always go with it.

The status bar says what a drop will do while you drag.

Dragging thumbnails to another application, such as Finder or Explorer, always copies them and leaves the originals in place.

Only the images are copied to another application. To include their sidecars, hold Shift as you start the drag.
