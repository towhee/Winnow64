Layers

The base layer is the original image. All edits are applied to the entire image. Raw image noise reduction is applied to the base image.

Additional layers each contain a layer mask. The layer mask is created and modified using mask tools (linear gradient, brush ...). Each mask tool can add to or subtract from the layer mask. While a mask is active, the edits to Basic, Color and Effects are localized to the layer mask.

Curves

The Curves panel shapes tone directly, and works two ways.

Parametric draws the curve your Basic tone sliders are already making, over the image's histogram. Drag up or down inside one of the four bands — blacks, shadows, highlights, whites — and that band's Basic slider moves with you; double-click a band to set it back to zero. The three handles under the plot set where the bands begin and end. They are the same handles that sit under the histogram at the top of the Develop panel, so moving one moves the other.

Point is the free-form curve. Click anywhere on the curve to add a point, drag it to move it, and double-click a point to remove it. Double-click the background to start over. The two end points cannot move sideways, but you can drag them up and down to set the black and white points.

The channel list next to the mode chooses which curve you are editing. RGB is the main curve and affects everything — an S shape adds contrast, a lifted bottom-left corner gives the faded, matte look. Red, Green and Blue edit one channel on top of the RGB curve, which is how you tint the shadows one colour and the highlights another.

Editing more than one image

Develop edits apply to every selected image. If more than one image is selected a red banner appears at the top of the Develop panel telling you how many, because the other images are not on screen while you edit. Each adjustment is copied to the other images as an absolute value, so Exposure +0.5 means +0.5 on all of them, whatever they started from. Only settings that you actually change are copied — the rest of each image's recipe is left alone.

Masks, spot heals and the crop are specific to the image they were made on and are never copied by an adjustment. Paste Settings (and applying a preset) also apply to the whole selection, and those do carry the crop and spot heals, because you asked for that exact recipe.

Raw Files

In the base layer you can choose to source: either the raw data or the embedded preview image all cameras save in the raw files. If you select 'Raw' then you can select how to demosaic (convert raw data into pixels). If you choose Winnow to demosaic, then you can also run noise reduction on the raw data, which is much better than running noise reduction later in the develop pipeline when the pixels are already 'baked'.

Export

Press X (or Develop > Export Developed Image) to write the selected images out with their develop settings applied. Every selected image is exported with its own recipe — masks, spot heals and crop included — not the recipe of the image you happen to be looking at.

The export dialog covers where the files go (a subfolder of the source folder, or any folder you choose), what they are called (a filename template plus a suffix, and what to do when the name already exists), the format, and the size. Beyond JPEG, PNG and BMP you can write TIFF — at 8 or 16 bits per channel, which is worth using when the image will be edited further — and, on macOS, HEIC. Turn on Copy metadata from the original to carry the camera, lens, date and copyright across; it costs about a fifth of a second per image.

Exporting a folder of raw files takes a while, so the export runs in the background: the progress bar counts the images and Stop ends the run, leaving the files already written in place.

Export presets

Save the settings in the export dialog as a named preset with New. An export preset remembers everything, including the destination folder, so Develop > Export with preset > your preset exports the selection immediately without opening the dialog at all. Use it for the exports you repeat — a web-sized JPEG, a full-size 16-bit TIFF for retouching.
