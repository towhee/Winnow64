Raw

What it does

The Raw panel sits at the top of the Develop dock and holds the decisions made before any adjustment: which data Winnow develops, how that data is turned into pixels, and whether noise is removed while it still can be removed cleanly. It appears for raw files only — a JPEG or a TIFF already is pixels, so there is nothing here to decide.

Everything in this panel feeds the base image. Change one of these and the whole recipe is re-rendered on the new base, which is why a change here can take a moment where a slider does not.

Edit: Raw or Embedded Preview

Every camera stores a finished JPEG inside the raw file — the picture you saw on the back of the camera. Raw develops the sensor data itself: the full tonal range, the real white balance, and everything below. Embedded Preview develops that camera JPEG instead.

The preview is quicker and it is the camera maker's own rendering, so it is a reasonable choice for a fast pass or a first look. It has been demosaiced, white balanced and contrast-mapped already, though, so the highlight and shadow headroom is gone and the raw-only controls below are hidden while it is selected.

Render using

Demosaic is the step that turns the sensor's one-colour-per-photosite grid into full-colour pixels. There are two engines:

  • Apple — Core Image's raw pipeline. Fast, and a known quantity.
  • Winnow — the in-house decoder. Slower, and the only route to the raw noise reduction below, which is the reason to choose it.

Noise Reduction

This is raw denoise: it runs on the sensor data before demosaic, while the noise is still the noise the sensor made. Later noise reduction works on pixels that have already been interpolated and tone-mapped, and the grain has been baked into them by then — which is why the result here is better than anything the pipeline can do downstream. It is offered with the Winnow engine only.

  • Auto run on: every raw file is denoised as you come to it. This applies to all images, including any you previously chose not to denoise.
  • Auto run off: the Run on this image box appears; tick it to denoise the current image. The choice is saved with that image's edits, so it stays denoised even when Auto run is off.
  • The Lum and Color amounts appear once the image has been denoised. Winnow remembers the last values you set and uses them for every image you have not adjusted yourself; an image you adjust keeps its own values.
  • Lum and Color set how much of each is removed — luminance grain and colour speckle are separate problems, and colour usually tolerates a much heavier hand than luminance, which is where detail lives.

When denoise cannot run, the group is greyed, the amounts are hidden, and the panel says why in their place, rather than accepting a click and quietly doing nothing.

What is saved

These are part of the develop recipe, stored on the Global scope in the image's sidecar: the edit source, the engine, the explicit denoise on/off and the two amounts. They are per image, so a folder can hold raws developed from the sensor data alongside raws developed from their previews.
