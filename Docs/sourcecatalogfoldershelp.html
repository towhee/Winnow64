The Source panel

The Source panel is where you say which images you are looking at. It has two subpanels, and they are two different answers to that one question:

  • Catalog — every image Winnow has indexed, wherever it lives, or one year of it.
  • Folders — the folders on your drives, chosen one at a time or several at once.

Choosing in either subpanel replaces what the other one had chosen: only one source is in effect at a time. Filtering, sorting and searching then mean the same thing whichever you picked — they work on the source you chose.

Catalog

Selecting the Catalog row looks at the whole catalog, the way clicking a folder looks at that folder. The number beside it is how many images have been indexed; if no number is shown, the catalog has not been opened yet, which is not the same as it being empty.

Expand the row to see the years in the catalog. Selecting a year does two things at once: it switches to the catalog and checks that year in the Filters panel. To widen it again, clear that year in Filters or select the Catalog row itself.

Picking a folder or a bookmark folds the years away again, so the folder tree gets the room back. It does not change what you chose — only what is showing.

The catalog holds what Winnow has scanned. Folders it has never visited are still reachable in the Folders subpanel below — they are simply not in the catalog yet.

Folders

Mouse clicking selects a folder. All selected folders' eligible images are displayed. You can change the selection behavior with the mouse modifier keys:

No modifier

The current selection of folders is cleared and the clicked folder is selected.

Ctrl/Cmd modifier

The folder selection is toggled. If the folder was selected then it will be unselected. If it was unselected then it will be selected. If only one folder is selected then it cannot be unselected.

Shift modifier

All folders from the prior selection to the current clicked folder will be selected. Toggle is ignored.

Alt/Opt modifier

The folder and all subfolders are recursively selected. Combine with Ctrl/Cmd to toggle selection. If only the Alt/Opt modifier is used, then any prior selection is cleared. If there are too many subfolders then the root folder will not expand, but all the subfolders will be loaded and the root folder text will change to orange.
