The Source panel

The Source panel is where you say which images you are looking at. The two buttons in its title bar are the two answers to that question, and one of them is always lit:

  • Folders — the folders on your drives. Clicking a folder loads it.
  • Library — every image Winnow has catalogued, wherever it lives, shown as its folders. The whole Library is loaded at once, so clicking a folder here filters to it rather than loading it.

Only one source is in effect at a time. Filtering, sorting and searching mean the same thing whichever you picked — they work on the source you chose. Clicking a folder or a bookmark switches to Folders; File > Open Library switches to the Library.

Library

The top row, Library, is the whole Library. The number beside it is how many images it holds; if no number is shown, the catalog has not been opened yet, which is not the same as it being empty. Beneath it are the folders you chose to catalog (Manage Catalog...), and the folders inside them. A folder whose drive is not connected is greyed.

Clicking a folder checks it in the Folders category of the Filters panel — the Library tree and that category are two views of the same filter, so a change in either shows in both.

No modifier

Shows the folder and every folder inside it. Clicking 2020-2029 shows the whole decade.

Alt/Opt modifier

Shows this folder only, without the folders inside it. In the Filters panel this reads as the folder included and each folder directly inside it excluded.

Ctrl/Cmd modifier

Adds the folder to what is shown, or removes it if it was already there.

Shift modifier

Shows every visible folder from the one clicked last to this one.

Clicking the Library row clears the folder filter and shows the whole Library again. Your other filters are left as they are.

Right-click a folder to reveal it in the Folders view or in the Finder/Explorer, or to open Manage Catalog. The Library holds what Winnow has scanned: folders it has never catalogued are still reachable under Folders.

Folders

Mouse clicking selects a folder. All selected folders' eligible images are displayed. You can change the selection behavior with the mouse modifier keys:

No modifier

The current selection of folders is cleared and the clicked folder is selected.

Ctrl/Cmd modifier

The folder selection is toggled. If the folder was selected then it will be unselected. If it was unselected then it will be selected. If only one folder is selected then it cannot be unselected.

Shift modifier

All folders from the prior selection to the current clicked folder will be selected. Toggle is ignored.

Alt/Opt modifier

The folder and all subfolders are recursively selected. Combine with Ctrl/Cmd to toggle selection. If only the Alt/Opt modifier is used, then any prior selection is cleared. If there are too many subfolders then the root folder will not expand, but all the subfolders will be loaded and the root folder text will change to orange.
