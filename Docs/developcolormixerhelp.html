Color Mixer

What it does

The Color Mixer adjusts colour by hue range. It works on eight ranges: Red, Orange, Yellow, Green, Aqua, Blue, Purple and Magenta. Each range has its own Hue, Saturation and Luminance slider. This is Lightroom's Color Mixer with Adjust set to HSL.

A slider moves every pixel of that hue, whatever its brightness. Bluer skies, a calmer orange skin tone or darker green foliage are each one slider.

Greys and near-greys are left alone, because their hue is mostly noise.

The controls

In the combined Color panel this is the Mix mode. The Hue, Saturation, Luminance and All buttons choose which sliders are shown. All shows the three groups of eight together.

Every slider runs from −100 to +100, with 0 meaning no change. Double-click a slider to return it to 0.

Hue shifts a range toward its neighbours. The slider's colours show the direction: Red moves toward Magenta (left) or Orange (right).

Saturation makes a range more or less colourful. At −100 the range becomes grey.

Luminance darkens (left) or brightens (right) a range.

A button whose group has edits is marked with a *, so you can see changes in a group that is not showing.

The section's [⋮] menu has Reset, and its eye is a before/after that keeps your values.

How the ranges blend

A colour between two range centres takes a smooth blend of both ranges' sliders, so there is no hard edge between them. Moving all eight sliders in a group by the same amount changes every colour by that amount.

Mix, Hue and Color Range masks

Mix selects by hue only: all the blues, light or dark, pale or vivid.

Hue (Point Color) selects one sampled colour by hue, saturation and lightness together. Use it when Mix would also move something else of the same hue.

A Color Range mask selects colours too, and can then apply any adjustment, not just hue, saturation and luminance.

Where it sits in the pipeline

The mixer runs after the tone curve and the Color panel's global Hue and Saturation. It runs before Point Color, so a Point Color sample sees the mixed colour.

The work is done on the colours as displayed, in a perceptual colour space (OKLab). This keeps a range's change even across it.

The strengths are first estimates and have not yet been matched to Lightroom's.
