What keywords are, and why you would want them

A keyword is a short label you attach to a photograph to say what is in it, where it was taken, or what it is for — Heron, Vancouver Island, Grandma, Client: Smith wedding. A photograph can have as many keywords as you like.

Folders and file names can only sort a picture one way. Keywords let the same picture be found many ways. A heron photographed on a family holiday can carry Heron, Holiday 2024 and Nanaimo, and you will find it whether you are looking for birds, that holiday or that town — years from now, without remembering which folder it went into.

Keywords are written into the photograph's own metadata (or into the small .xmp file beside it, for raw files), so Lightroom, Photoshop, Bridge and most other photo programs can read them too. They are not locked inside Winnow.

What the Keyword list is

The Keyword list is the bottom part of the Keywords panel. It is your vocabulary: the set of keywords you have decided to use, like a dictionary you build up over time. Keeping one list, rather than typing a fresh word each time, means you always spell a keyword the same way — so Heron finds every heron, not just the ones you did not type as heron or Herons.

The list and your photographs are separate. Changing the list (adding, renaming, moving, deleting a keyword) changes the list. A photograph only changes when you put a keyword onto it or take one off — or when Winnow asks you first and you say yes.

Branches: keywords inside keywords

Keywords can be filed inside other keywords, like folders inside folders. A keyword with others inside it is a branch; click its arrow to open or close it. For example:

Fauna
    Bird
        Heron
        Eagle
Location
    Canada
        BC
            Nanaimo

Why bother? Because a branch finds everything inside it. Filter on Bird and you get your herons and your eagles at once, without tagging every photograph with Bird as well as Heron. It also keeps a long list readable, and lets the same name mean two different things: a Vancouver in Canada and a Vancouver in Washington can each sit in their own branch and keep their own photographs.

What you see in the list

  • The number beside a keyword is how many of your photographs carry it, including everything inside it. A blank means none. Only photographs Winnow has catalogued are counted; File > Manage Catalog... is where you choose which folders those are.
  • A keyword drawn in dull yellow is one the current photograph already has.
  • Hover over a keyword to see its whole path, such as Fauna > Bird > Heron.
  • The Find keyword box above the list hides everything that does not match what you type, so you can find a keyword in a long list. Its branches stay visible so you can see where it sits.

Everyday use

  • To tag photographs: select them in the thumbnails, then double-click a keyword in the list (or select it and press Return). You can also drag the photographs onto the keyword.
  • To see every photograph with a keyword: click it once. Winnow shows only the photographs that carry it. (This clears any other filter first.)
  • To move a keyword into a different branch: drag it onto the branch. A keyword cannot be dropped inside itself; the cursor tells you before you let go.
  • To take a keyword off a photograph: use the tags at the top of the Keywords panel and click the × on the tag.

The right-click menu, item by item

Right-click any keyword in the list (or the empty space below it) for these commands.

Add "keyword" to selected images

What it does: tags every selected photograph with the keyword you right-clicked.

Why: the same as a double-click, for when you would rather use a menu.

How: select the photographs first, then right-click the keyword.

Rename...

What it does: changes a keyword's name — to fix a spelling mistake, or change Birds to Bird.

How: right-click the keyword, choose Rename..., type the new name. (F2 does the same.)

What happens to your photographs: the list changes straight away. Photographs already tagged with the old name still have it in their files, so Winnow asks what to do, and tells you how many photographs each choice would change:

  • This folder — update only the photographs in the folder you are looking at.
  • Everywhere — update every catalogued photograph that has it, even in folders that are not open.
  • Not now — leave the files alone. Those photographs show the old keyword as a red tag, so you can deal with them later.

Moving a keyword by dragging it asks the same question, for the same reason.

New keyword inside... / New keyword...

What it does: adds a new keyword to your list. Right-click a keyword and the new one goes inside it; right-click the empty space below the list and it goes at the top level.

Why: to build your vocabulary before you need it, or to make a home for a new subject — add Kingfisher inside Bird, ready to use.

Note: this only adds a word to your list. No photograph is tagged until you tag it.

Insert parent above...

What it does: creates a new branch and moves the keyword you right-clicked into it.

Why: for when you realise a keyword belongs inside a branch that does not exist yet. If Canada sits on its own at the top level, insert a parent called Location above it, and Canada — with everything inside it — moves into Location.

Note: this changes the keyword's path, so like Rename it asks whether to update your photographs.

Delete keyword

What it does: removes the keyword, and anything inside it, from your list.

What it does not do: it does not remove the keyword from photographs that already have it. They keep it in their own files, where it shows as a red tag (a keyword that is not in your list). Winnow tells you how many photographs that is before you confirm.

Why: to clear out a keyword you have stopped using, or one created by mistake.

Tidy flat keywords...

What it does: files loose keywords into your branches, in your list and in your photographs, all in one go.

Why: photographs keyworded by other programs, or by you before you used branches, often carry bare names — Nanaimo rather than Location > Canada > BC > Nanaimo. They still work, but they pile up at the top of your list beside the branches they belong in, and a search on Canada does not find them. On a large library there can be hundreds; filing them one by one would take all day.

How:

  1. Choose Tidy flat keywords.... Winnow lists every loose keyword, how many photographs carry it, and the branch in your list it matched.
  2. For each one, choose Move (into the branch shown; you can pick another), Remove (take the bare name off those photographs) or Leave alone. Winnow suggests an answer for every row. Rows marked review matched more than one branch — hover over them to see the choices.
  3. Use the Show list to deal with a whole group at once, for example everything that matched exactly one branch.
  4. Press Apply. Winnow tells you how many photographs will be changed and asks once more. While it works, a progress bar shows how far it has got.

Apply rewrites the keywords in every affected photograph, in every catalogued folder, and cannot be undone from inside Winnow. If you are unsure, use Leave alone, or back up your photographs (and their .xmp files) first.

Audit keywords...

What it does: finds photographs whose keywords look wrong, by comparing each photograph with your other photographs that have the same keyword. It reports two kinds of finding:

  • Suspect — "tagged Egret, but looks like your Heron images".
  • Missing — "not tagged Heron, but looks like your Heron images".

Why: after years of keywording, mistakes creep in — a mis-click, a keyword applied to the whole selection when one picture was different. They are almost impossible to find by looking. The audit learns what your photographs of each keyword look like, so it works for places and people, not just objects.

How: press Run Audit. The first time, Winnow downloads the image-recognition model it needs, and looking at every photograph can take several minutes on a large library; later runs only look at what has changed.

Then work through the findings: Replace, Remove, or Keywords Are Right (Winnow remembers that, and does not ask about it again). Nothing changes in your photographs until you press Apply Changes.

Note: the audit can only learn a keyword that enough of your photographs already carry, so it works best on a library that is already mostly keyworded.

Build vocabulary from catalog

What it does: adds to your list every keyword found in the photographs Winnow has catalogued.

Why: if your photographs were keyworded before you started using Winnow (in Lightroom, Photo Mechanic, or anything else), this gives you a list straight away, without typing.

Safe to run any time: it only adds. It never removes or renames anything, and running it again only adds what is new. Your photographs are not changed.

Import Lightroom keywords...

What it does: reads a keyword list exported from Lightroom (Metadata > Export Keywords... in Lightroom Classic) and merges it into yours, branches and synonyms included.

Why: if you already keep a carefully organised keyword list in Lightroom, you do not have to build it again.

Safe to run any time: like Build vocabulary, it only adds; a keyword you already have is left as it is. If anything could not be added, Winnow tells you which.

Export keywords...

What it does: saves your list to a file in Lightroom's keyword format.

Why: to load your vocabulary into Lightroom (Metadata > Import Keywords...), to share it with another computer or another person, or simply to keep a backup of your list.

Where to start

  • Never used keywords before? Add a few top-level branches you care about — perhaps People, Places and Subjects — with New keyword..., add keywords inside them as you need them, and tag a few photographs by double-clicking. Click a keyword to see it working.
  • Photographs already keyworded elsewhere? Run Build vocabulary from catalog (or Import Lightroom keywords... if you have an export), then Tidy flat keywords... to file the loose ones into branches.
  • A big, long-keyworded library? Run Audit keywords... now and then to catch mistakes.

For the tags at the top of the panel, and for filing keywords by dragging them from the Filters panel, press the ? in the Keywords panel title bar.
